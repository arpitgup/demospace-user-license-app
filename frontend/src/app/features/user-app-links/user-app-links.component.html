Demo Summary

{{ demoDetails.demo_title }} showcases 1st Party (Google Workspace) and 3rd Party search and summarization results.

  • Google Licenses: This application allows Googlers to create demo profiles within a dedicated environment for showcasing Gemini Enterprise. Demo users are issued Google Workspace Enterprise Plus and Gemini Enterprise Plus licenses. See How to login section for more.
  • For 3rd party resources: The License reservation feature (see left menu) allows users to reserve Third Party licenses for this demo. Reservations are only needed to SSO into the third party platform(s) i.e. reservations are not needed to use this demo. We are actively working on adding more platform access. See demo guide for more.
  • Chrome Profile: Once you are in the demo environment, create a Chrome profile for your demo user for easy access. Please see the latest Demo Guide for more.
